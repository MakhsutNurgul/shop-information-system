# Дүкеннің ақпараттық жүйесі — Use Case

## Актерлер

### Әкімші

Әкімші жүйені басқарады.

Негізгі әрекеттері:

* Тауар қосу;
* Тауарды өзгерту;
* Тауарды өшіру;
* Клиенттерді басқару;
* Сатылымдарды бақылау;
* Есеп алу.

### Сатушы

Сатушы дүкендегі күнделікті сатылым жұмыстарын орындайды.

Негізгі әрекеттері:

* Тауарды іздеу;
* Тапсырыс қабылдау;
* Тапсырысты рәсімдеу;
* Сатылымды тіркеу.

### Клиент

Клиент дүкеннен тауар сатып алады.

Негізгі әрекеттері:

* Тауарларды қарау;
* Тауарды таңдау;
* Тапсырыс беру;
* Тапсырыс статусын көру.
