# Дүкеннің ақпараттық жүйесі

## Жоба туралы

Бұл жоба дүкеннің негізгі жұмыс процестерін ақпараттық жүйе арқылы басқаруға арналған.

Ақпараттық жүйе арқылы тауарларды басқару, клиенттер туралы ақпаратты сақтау, тапсырыстарды рәсімдеу және сатылымдарды бақылау мүмкіндігі қарастырылады.

## Жобаның мақсаты

Дүкендегі негізгі бизнес-процестерді автоматтандыру және ақпаратты бір орталықта сақтау.

## Негізгі функциялар

* Тауарларды тіркеу;
* Тауарлар туралы ақпаратты өзгерту;
* Тауарларды іздеу;
* Клиенттер туралы ақпаратты сақтау;
* Тапсырыс қабылдау;
* Тапсырысты өңдеу;
* Сатылым туралы ақпаратты сақтау;
* Тауар қалдығын бақылау;
* Есеп беру.
